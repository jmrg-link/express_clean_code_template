# S3 — Object Storage

Store user files in S3 with presigned URLs, CORS, and automatic lifecycle management.

## Qué?

S3 stores objects with 99.999999999% durability. No server to manage.

## Por qué?

Files pile up on disk fast. S3 offloads that to AWS. Users upload directly to S3 via presigned URLs, bypassing the API entirely.

## Para qué?

- Archivos de perfil, documentos de usuarios (prod)
- Archivos staging para testing (staging)
- Backups automáticos de MongoDB (backups bucket)

## Buckets

| Bucket | Propósito | Región | Público | Ciclo vida |
|---|---|---|---|---|
| `app-prod-bucket` | Archivos usuarios prod | us-east-1 | No (presigned) | 90 días → Glacier |
| `app-staging-bucket` | Testing, staging | us-east-1 | No | 7 días → delete |
| `app-prod-backups` | MongoDB dumps diarios | us-east-1 | No | 30 días → delete |

## Configuración inicial

### Crear buckets

```bash
# Production
aws s3api create-bucket \
  --bucket app-prod-bucket \
  --region us-east-1

# Staging
aws s3api create-bucket \
  --bucket app-staging-bucket \
  --region us-east-1

# Backups
aws s3api create-bucket \
  --bucket app-prod-backups \
  --region us-east-1
```

### Bloquear acceso público

```bash
for bucket in app-prod-bucket app-staging-bucket app-prod-backups; do
  aws s3api put-public-access-block \
    --bucket $bucket \
    --public-access-block-configuration \
      BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
done
```

## Presigned URLs

API genera URLs temporales (15 min) para descarga/upload sin exponer credenciales AWS.

### Flujo E2E: Upload de archivo

```
Cliente (navegador)
  ↓
GET /api/storage/upload-url?filename=profile.jpg
  ↓ (API)
S3StorageAdapter.getPresignedUrl('PUT', 'users/123/profile.jpg')
  ↓
Devuelve URL firmada válida 15 min
  ↓
Cliente: PUT https://app-prod-bucket.s3.amazonaws.com/users/123/profile.jpg?X-Amz-Signature=...
  ↓ (sin pasar por API)
S3 valida firma, acepta upload
```

### Implementación API

```typescript
// src/infrastructure/services/s3/s3-storage.adapter.ts

async getSignedDownloadUrl(key: string, expiresInSeconds = 900): Promise<string> {
  const cmd = new GetObjectCommand({ Bucket: this.bucket, Key: key });
  return await getSignedUrl(this.client, cmd, { expiresIn: expiresInSeconds });
}

async putObject(key: string, body: Buffer): Promise<void> {
  await this.client.send(
    new PutObjectCommand({
      Bucket: this.bucket,
      Key: key,
      Body: body,
      ContentType: 'application/octet-stream',
    }),
  );
}
```

### Comando CLI: generar presigned URL manualmente

```bash
aws s3 presign s3://app-prod-bucket/users/123/profile.jpg \
  --expires-in 900 \
  --region us-east-1
```

## CORS

Permitir uploads desde navegador sin CORS error. Necesario si el frontend está en dominio diferente (ej. `app.example.com` vs S3 endpoint).

```bash
aws s3api put-bucket-cors \
  --bucket app-prod-bucket \
  --cors-configuration '{
    "CORSRules": [
      {
        "AllowedOrigins": ["https://app.example.com"],
        "AllowedMethods": ["GET", "PUT", "POST", "DELETE"],
        "AllowedHeaders": ["*"],
        "ExposeHeaders": ["ETag", "x-amz-version-id"],
        "MaxAgeSeconds": 3000
      }
    ]
  }'
```

## Encryption

S3 encrypts everything at rest by default. You can choose SSE-S3 (AWS manages keys) or SSE-KMS (you manage keys).

```bash
# SSE-S3: simple, recomendado para data no ultra-sensible
aws s3api put-bucket-encryption \
  --bucket app-prod-bucket \
  --server-side-encryption-configuration '{
    "Rules": [{
      "ApplyServerSideEncryptionByDefault": {
        "SSEAlgorithm": "AES256"
      }
    }]
  }'

# Verificar
aws s3api get-bucket-encryption --bucket app-prod-bucket
```

## Lifecycle

Auto-delete u archive objetos viejos. Ahorra costos (Glacier/Deep Archive < S3 Standard).

```bash
# Delete archivos staging > 7 días
aws s3api put-bucket-lifecycle-configuration \
  --bucket app-staging-bucket \
  --lifecycle-configuration '{
    "Rules": [
      {
        "ID": "DeleteOldStaging",
        "Status": "Enabled",
        "Filter": {"Prefix": ""},
        "Expiration": {"Days": 7}
      }
    ]
  }'

# Archive prod > 90 días a Glacier (30% del costo)
aws s3api put-bucket-lifecycle-configuration \
  --bucket app-prod-bucket \
  --lifecycle-configuration '{
    "Rules": [
      {
        "ID": "ArchiveOldFiles",
        "Status": "Enabled",
        "Filter": {"Prefix": "users/"},
        "Transitions": [
          {
            "Days": 90,
            "StorageClass": "GLACIER"
          }
        ]
      }
    ]
  }'

# Delete backups > 30 días
aws s3api put-bucket-lifecycle-configuration \
  --bucket app-prod-backups \
  --lifecycle-configuration '{
    "Rules": [
      {
        "ID": "DeleteOldBackups",
        "Status": "Enabled",
        "Filter": {"Prefix": "mongo/"},
        "Expiration": {"Days": 30}
      }
    ]
  }'
```

## Versioning

Recuperar objetos eliminados accidentalmente. Ocupa espacio extra (todas las versiones se cobran).

```bash
# Enable
aws s3api put-bucket-versioning \
  --bucket app-prod-bucket \
  --versioning-configuration Status=Enabled

# List versions (incluye deleted markers)
aws s3api list-object-versions --bucket app-prod-bucket

# Restore deleted object
aws s3api copy-object \
  --bucket app-prod-bucket \
  --copy-source app-prod-bucket/users/123/profile.jpg?versionId=ABC123 \
  --key users/123/profile.jpg
```

## Logging

Auditar quién accede a qué. Logs se guardan en el mismo bucket (ó diferente para mayor control).

```bash
aws s3api put-bucket-logging \
  --bucket app-prod-bucket \
  --bucket-logging-status '{
    "LoggingEnabled": {
      "TargetBucket": "app-prod-bucket",
      "TargetPrefix": "logs/s3-access-logs/"
    }
  }'

# Query logs
aws s3 ls s3://app-prod-bucket/logs/s3-access-logs/ --recursive
```

## Bucket Policy (IAM minimalista)

Restricción adicional: solo ciertas roles pueden escribir.

```bash
aws s3api put-bucket-policy \
  --bucket app-prod-bucket \
  --policy '{
    "Version": "2012-10-17",
    "Statement": [
      {
        "Effect": "Allow",
        "Principal": {
          "AWS": "arn:aws:iam::ACCOUNT:role/ec2-instance-role"
        },
        "Action": [
          "s3:GetObject",
          "s3:PutObject",
          "s3:DeleteObject",
          "s3:ListBucket"
        ],
        "Resource": [
          "arn:aws:s3:::app-prod-bucket",
          "arn:aws:s3:::app-prod-bucket/*"
        ]
      }
    ]
  }'
```

## Cross-Region Replication (Futuro)

Para HA: replicar bucket a región secundaria automáticamente.

```bash
# Habilitar versioning primero
aws s3api put-bucket-versioning \
  --bucket app-prod-bucket \
  --versioning-configuration Status=Enabled

# Crear role de replicación
aws iam create-role --role-name s3-replication-role \
  --assume-role-policy-document '{
    "Version": "2012-10-17",
    "Statement": [{
      "Effect": "Allow",
      "Principal": {"Service": "s3.amazonaws.com"},
      "Action": "sts:AssumeRole"
    }]
  }'

# Configurar replicación
aws s3api put-bucket-replication \
  --bucket app-prod-bucket \
  --replication-configuration '{...}'  # ver AWS docs
```

## Costos

| Concepto | Tarifa | Nota |
|---|---|---|
| Almacenamiento Standard | $0.023/GB/mes | Archivos activos < 90 días |
| Almacenamiento Glacier | $0.004/GB/mes | Backups 90+ días |
| Solicitudes GET | $0.0004 por 10k | Presigned URLs cuestan |
| Transferencia OUT | $0.09/GB | Salida a Internet |
| **Free tier** | 5 GB + 20k GETs | Primer año |

**Estimado prod:** 50 GB usuarios + 20 GB backups ≈ $1.50/mes (dentro free tier).

## Troubleshooting

### "InvalidAccessKeyId" en CLI
```bash
# Verificar credentials
aws sts get-caller-identity
# Si falla, reconfigurar: aws configure
```

### "SignatureDoesNotMatch" en presigned URL
Firma expirada o credenciales incorrectas en EC2 instance role.

```bash
# En EC2: verificar role attached
aws iam get-role --role-name ec2-instance-role
```

### Bucket "already exists"
El nombre debe ser globalmente único en AWS.

```bash
# Usa timestamp
aws s3api create-bucket --bucket app-prod-bucket-$(date +%s)
```
